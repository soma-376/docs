# PROJ-107 사용자 인증 후속 티켓 초안

이 문서는 로컬 초안이다. Jira 이슈를 생성하거나 완료 처리하지 않았다.

## telemetryctl 사용자 로그인
- 연결: PROJ-107 서버 계약을 선행으로 둔다.
- 구현: login 명령, 브라우저 시작, 127.0.0.1/::1 동적 포트 callback, state 비교, S256 코드 교환, 사용자 세션 키링 항목.
- 설치 pit_/ptt_와 사용자 RT를 분리한다. 기존 credential 계정 이름을 덮어쓰지 않는다.
- AC: state/PKCE 실패, 코드 만료, 키링 실패, RT 갱신 직렬화, 재사용/응답 유실 시 재로그인.

## frontend 가입·로그인 화면
- 연결: PROJ-107 JSON API와 PROJ-109 인가.
- 구현: 초대 기반 최초 비밀번호 설정, tenant 식별과 로그인, CLI authorize 요청·callback 이동.
- 웹 토큰 저장 방식은 프런트 구현 ADR에서 정하며 현재 JSON 계약을 쿠키 구현으로 오해하지 않는다.
- AC: 가입/설치 어느 순서든 로그인 가능, 잠금·재시도 표시, 회원/관리자 대시보드 인가 분리.
