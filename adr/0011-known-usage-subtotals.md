# 0011. 계산 가능한 관측 부분합을 전체 확정값과 분리해 표시한다

## Status

Accepted — 기존 전체값의 null·완전성·가격판 규칙은 유지하고 부분합 조회를 추가한다.

## Context

backend와 frontend가 함께 반환·표시하는 과거 사용량에는 보관 공백과 공시 단가가 없는 모델이 섞일 수 있다. 전체 환산액은 미확정이지만 계산 가능한 관측까지 화면에서 사라지면 실제 사용을 검토하기 어렵다. 원천 날짜·토큰·모델을 바꾸거나 공백을 0으로 채워 해결할 수 없다.

## Decision

- 기존 `equivalentCostUsd`, 사용자당·세션당 지표, 비중·비교·알림의 의미를 유지한다. 미가격 행이 있으면 전체 환산액은 null이다.
- 개요 summary와 trend point, 팀 metrics와 trend point에 `knownEquivalentCostUsd`, `pricedUsageRows`, `unpricedUsageRows`를 추가한다. 개요와 팀 metrics의 부분합은 기존 `Value<string>`이고 팀 trend는 nullable USD 문자열이다. 행 수는 해당 범위의 primary 사용 관측 수다.
- 부분합은 같은 가격판에서 금액을 계산한 행만 더한다. 계산한 행이 없거나 가격판이 혼재하면 null이다. 완전하게 관측한 빈 범위만 0이다. 미가격 행은 `pricing_missing`, 기간 불완전은 기존 상세 사유로 표시한다. 실제 0원 관측은 유지한다.
- 개요의 전체 금액은 그대로 표시하고 부분합을 별도 보조값·추이로 제공한다. 부분합을 전체 금액·평균·비중으로 복사하지 않는다.
- 팀 비용·토큰 차트는 기존 전체 누적 모드와 별도로 `확인된 값 누적`을 제공한다. 비용은 known 금액, 토큰은 그날의 기존 토큰값이 확인 가능한 날만 누산한다. 미관측·확인 불가 날짜는 null 공백으로 남기고 이후 관측일에 앞서 확인된 값의 합을 표시한다. 공백을 선으로 연결하지 않는다.
- 세션 누적은 기존 고유 세션·완전성 규칙을 유지한다. 일별 세션 수를 더하지 않는다.
- 차트 옆에서 부분합임과 선택 기간 전체 사용량이 아님을 항상 설명한다. 기존 자료의 누락을 실제 사용 0으로 주장하지 않는다. CSV도 같은 보조값·행수·표시 모드를 보존한다.

## Alternatives Considered

전체 환산액을 부분합으로 바꾸는 방법은 평균·비중·알림의 의미를 바꾸므로 제외한다. 공백을 0으로 메우는 방법은 수집 근거를 만들므로 제외한다. 전체값만 표시하는 방법은 검토 가능한 자료도 숨기므로 제외한다.

## Consequences/Tradeoffs

### Positive

원본과 기존 계약을 보존하면서 계산 가능한 실제 사용량을 검토할 수 있다.

### Negative

전체값과 관측 부분합이 공존하므로 표시 이름과 설명이 필요하다. 토큰 부분 누적은 일부 성분만 있는 날짜의 알려진 성분까지 합산하지 않는다.

## Acceptance Criteria

미가격·전부 미가격·실제 0·빈 기간·가격판 혼재 시험, 공백 후 관측 누적 시험, 동일 원천으로 산출한 독립 부분합과 API·브라우저 표시의 일치로 검증한다.
